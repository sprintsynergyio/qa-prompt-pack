# Industry pack research (v0.2)

Theme selection, not prompt text. The 16 industry prompts were written for this pack. We did not quote vendor or blog prompts: the public ones we found were long articles, and there was no short, credited original that was a fair A/B pair.

Used to decide what QA teams in each domain actually test:

## Healthcare
- QAreMed, test data management and synthetic PHI: https://qaremed.com/guides/test-data-management-healthcare/ and https://qaremed.com/guides/synthetic-phi-test-data/
- Accountable, HIPAA-compliant test data: https://www.accountablehq.com/post/hipaa-compliant-healthcare-test-data-management-best-practices-and-practical-steps
- MITRIX, clinical workflow QA: https://mitrix.io/blog/healthcare-qa-testing-clinical-workflows/

## Financial
- QABattle, payment gateway checklist: https://qabattle.com/blog/test-cases-for-payment-gateway
- Merchant Plugins, payment API checklist (refunds, minor units, fraud): https://merchantplugins.com/payment-api-testing-checklist/
- QASkills, fintech compliance and audit trails: https://qaskills.sh/blog/fintech-qa-compliance-testing-guide
- QAble, net-banking limits: https://www.qable.io/knowledge-hub/test-cases/net-banking-transactions

## E-commerce
- QASphere, peak-season checklist: https://qasphere.com/blog/ecommerce-qa-peak-season/
- TestChimp, cart and coupon scenarios: https://testchimp.io/guides/verticals/testing-ecommerce-cart-and-coupons/
- LoadTester, peak and checkout load: https://loadtester.org/ecommerce-performance-testing and https://loadtester.org/checkout-load-testing
- Drizz, inventory race conditions: https://www.drizz.dev/post/mobile-testing-ecommerce-apps

## SaaS
- RAITHub, what to test in SaaS (isolation, RBAC, billing): https://www.raithub.com/blog/qa-testing-services-for-saas-companies
- QAPractices, multi-tenant isolation checklist: https://qapractices.com/checklists/multi-tenancy-saas-testing-checklist/
- Testriq, billing proration and API contracts: https://www.testriq.com/saas-platform-testing-services
- TestSprite, SaaS testing guide: https://www.testsprite.com/blog/how-to-test-a-saas-application-a-complete-quality-guide
